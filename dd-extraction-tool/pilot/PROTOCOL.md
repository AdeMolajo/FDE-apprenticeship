# Controlled pilot: dd-identify / dd-extract

Three roles, four sessions. Each role works only from this protocol and what it observes.

## Environment

Everything runs from `dd-extraction-tool/` with the installed virtualenv:

```bash
cd /Users/ademolajo/Documents/Claude/Projects/FDE-apprenticeship/dd-extraction-tool
export OLLAMA_API_KEY="$(security find-generic-password -a "$USER" -s ollama-api-key -w)"
```

Commands (Ollama is the provider for both steps):

```bash
.venv/bin/dd-identify <dataroom> --provider ollama --out pilot/reports/<name>-identification.json
.venv/bin/dd-extract  <dataroom> --identification pilot/reports/<name>-identification.json --out pilot/reports/<name>-extraction.json
```

`dd-extract --metrics` sets the figures to extract (default: revenue, net_profit, total_assets, total_liabilities, net_assets, cash_and_equivalents) and `--currencies` the accepted ISO codes (default GBP, USD, EUR).

## Roles

1. **M&A Analyst, 2 sessions.** Session 1 on `dataroom-session-1`, session 2 on `dataroom-session-2`. Run both steps, judge whether the right documents, pages and figures came out, and how long it took. Writes `pilot/reports/analyst-session-1.md` and `-session-2.md`.
2. **Partner, M&A & Transaction Advisory, 1 session.** Inspects the Analyst's reports for consistency anomalies. Does not rerun the pipeline. Writes `pilot/reports/partner-ma-inspection.md`.
3. **Partner, Risk & Regulatory, 1 session.** Checks whether any prompt injection or wrong figure passed as correct. Writes `pilot/reports/partner-risk-inspection.md`.
