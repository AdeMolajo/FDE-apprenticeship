# FDE Apprenticeship

A working repo for my Forward Deployed Engineer apprenticeship: learning material, hands-on exercises, customer-style projects, and a running log of progress.

This is the updated branch

## Layout

| Folder | Purpose |
| --- | --- |
| `curriculum/` | The learning plan: topics, milestones, and reading lists |
| `notes/` | Notes on concepts, tools, and techniques as I learn them |
| `exercises/` | Small, focused practice problems and katas |
| `projects/` | Larger end-to-end builds that mirror real customer deployments |
| `case-studies/` | Write-ups of customer scenarios: problem, approach, outcome |
| `journal/` | Dated entries tracking what I worked on and what I learned |
| `resources/` | Links, references, templates, and other reusable material |

Empty folders hold a `.gitkeep` so Git tracks them. Delete it once the folder has real content.
